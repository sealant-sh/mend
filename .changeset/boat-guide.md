The Boat operating guide (docs.mend.run/operate/boat) is one guide again, for the person who runs
the server and for an organization's owner. It covers turning Boat on, which Boat key a session
uses, creating a key with the permissions Mend needs, what each kind of key bills, checking a key
and the full check, where each organization's sessions run and what Boat cannot run, hot sessions,
the idle stop, images and saved snapshot slots, removing or replacing a key, and troubleshooting.
The server environment reference lists every Boat setting in `server.env`, and the CLI reference no
longer suggests reading a Boat key from a file. A test checks every `mend` command and flag the
guide names against the help catalog.
