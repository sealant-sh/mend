Add Antigravity (`agy`) as a first-class terminal coding-agent harness across Mend: connect an
Antigravity Google login (`mend connect antigravity`), launch sessions with `mend antigravity` (or
`mend agy`) and the web composer, pick Antigravity models and thinking effort from `mend models`,
sync personal skills into `~/.gemini/config/skills/`, and expose the Mend MCP server inside
Antigravity workspaces. Pins sealant `0.40.0-next.933`.
