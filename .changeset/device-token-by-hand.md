A device token minted by hand. Settings → Devices gains "Mint a token by hand": name the device and
Mend mints the same token a pairing claim would, shown once beside the configured origins, for a
device that cannot scan a code: an App Review tester, a headless box. It lists and revokes like any
paired device. `POST /api/me/devices` carries it.
