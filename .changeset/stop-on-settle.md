Settling a thread in T3 Code can now stop its Mend session too. Turn on **Settings → Sessions → T3
Code → Settling a thread stops its session**; it is off by default and kept per person. The session
stops as Stop does, with its work saved, so an idle session no longer waits for the idle stop once
you have put its thread away. A settle is still refused while the agent is working.
